# Emo AI – Advanced Desktop Assistant 🤖

Emo AI is a playful desktop AI assistant powered by Ollama and Python.
It combines chat, voice, image generation, camera control, PC automation, and a custom animated interface into one local AI companion.

Built with Python, Tkinter, Ollama, OpenCV, and custom automation tools.

## ✨ Features

* 💬 Local AI chat using Ollama
* 🧠 Memory system (remembers conversations)
* 🗣️ Voice speech system
* 🎨 AI image generation
* 📸 Camera capture support
* 🖥️ Open apps and files naturally
* 🌍 Google Maps integration
* 😀 Animated AI face with emotions
* ⚡ Multi-threaded responsive UI
* 🔒 Fully local AI support

## 🛠️ Technologies Used

* Python
* Tkinter
* Ollama
* OpenCV
* Requests
* Threading
* JSON Memory Storage

## 📦 Commands Examples

* `open chrome`

* `find nearest coffee shop`
* `draw anime dragon`

## 🚀 How To Run

1. Install Ollama
2. Run:

   ```bash
   ollama serve
   ```
3. Pull a model:

   ```bash
   ollama pull qwen2.5:3b
   ```
4. Run Emo AI:

   ```bash
   python emo.py
   ```
